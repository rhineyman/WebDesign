# Assignment 4
My styling choices for colors and lines is mostly for simplicity at the moment. My vision for building a pretty site is not exactly great so I spent more time on the functionality than anything. I chose "Press Start 2P" and "Limelight" google fonts because I felt they fit the theme well and weren't to obnoxious. The table I created holds the information for the game author and genre. This seemed like a good place to start for figuring out how to get it on the site. This is also a data set that works well with in the table. The form I built is just a standard sign up form for creating an account. The gallery could be theoretically used for images of achievements like your current rank in a game for example. I am discovering that my biggest issue with design is my lack of creative vision for building something new. Currently I am happy with just making things work and I know the styling will get better with time.
